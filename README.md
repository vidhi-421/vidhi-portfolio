## Featured Projects

### 1. n8n Feedback Analyser
An automated feedback-analysis workflow designed to organise responses, identify sentiment and feedback categories, prioritise issues, and suggest actionable insights.

**Areas:** Workflow Automation, n8n, AI, Sentiment Analysis

### 2. SafetyReady
A pharmacovigilance and regulatory submission-readiness platform designed to analyse adverse-event reports using a deterministic Proportional Reporting Ratio (PRR) pipeline with 95% confidence intervals. It also checks dossier outlines against ICH Common Technical Document (CTD) requirements and highlights missing items.

**Areas:** Pharmacovigilance, Data Analysis, Drug Safety, ICH CTD

### 3. Healthcare Claims Intelligence
An AI-powered system designed to investigate healthcare claims, validate supporting evidence, and identify suspicious or inconsistent healthcare activity using live web intelligence and TinyFish integration.

**Areas:** AI, Evidence Validation, Healthcare Research, TinyFish
